# ad-motsu.github.io

個人で制作・公開しているWebページを集約してホスティングするリポジトリです。

- 公開URL: [https://ad-motsu.github.io/](https://ad-motsu.github.io/)

---

## ディレクトリ構成

```text
.
├── index.html                 ポータル（制作・公開ページ一覧）
├── 404.html                   404エラーページ
├── favicon.svg                ファビコン
├── .nojekyll                  GitHub PagesでのJekyll処理無効化
├── README.md                  本ファイル
├── comiket/
│   └── index.html             コミケ サークル参加メモ
└── tools/
    ├── check.py               公式サイトから日付候補を抽出するツール
    ├── PROMPT.md              コミケページの更新手順・プロンプト
    └── out/                   抽出結果（gitignore対象。公式サイトの本文を再配布しないため）
```

計画書・実装仕様書は、リポジトリの棚卸し結果など公開に適さない内容を含むため、
このリポジトリには置かず手元の `_private/`（gitignore対象）で管理しています。

---

## ページを追加する手順

1. ルート直下に新しいディレクトリを作成し、単一HTMLの `index.html` を配置します（例: `new-app/index.html`）。
2. ルートの `index.html` 冒頭にある `PAGES` 配列に1行追加します。

```javascript
const PAGES = [
  // ...
  {
    name: "新ページのタイトル",
    href: "new-app/",
    summary: "ページの概要説明（1〜2文）",
    tags: ["タグ1", "タグ2"],
    updated: "YYYY-MM-DD",
    status: "public" // 準備中の場合は "wip"
  }
];
```

## 設計方針：共通CSS・共通JSを作らない理由

本リポジトリでは、**各ページを単一HTMLファイル内で自己完結させ、共通CSS・共通JSファイルを作成しません。**

- **波及事故の防止**: 各ページは半年に1度など低頻度でしか更新されない運用であり、かつテーマや世界観が無関係なページが増えていく前提です。
- 1つのページの編集・修正が他のページに波及・影響する経路を構造的に遮断し、長期間にわたって安全かつ独立して管理できるようにしています。

---

## 各ページの更新手順

- **コミケ サークル参加メモ (`comiket/`) の更新**:
  `tools/PROMPT.md` に記載の手順に従って更新作業を実施してください。
  `python3 tools/check.py <回数> --year <年>` で公式サイトから情報を取得し、差分を適用します。

## 公開サイトに掲載してはいけない情報（セキュリティ・プライバシー規約）

本サイトおよび公開リポジトリには、以下の機密情報・個人情報を**絶対に掲載しないでください**：

- サークル名
- 申込責任者の氏名・自宅住所・電話番号・個人メールアドレス
- 受付番号・申込書番号
- 払込金受領証の内容そのもの
- Circle.ms 等のアカウント認証情報（パスワード・APIキー・トークン）
- サークルカット画像
- 公式PDFそのもの（再配布禁止）

※「申込書番号は払込金受領証に書いてある」「Circle.msのログインが必要」といった**手続き上の在り処や要件のメモは記載可**ですが、**値そのものの記載は禁止**です。
